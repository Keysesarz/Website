# Kc Saraza — My Digital Journey

## Files
- index.html — page structure and content
- style.css — responsive modular-grid design
- script.js — navigation, filters, search, modals, forms, and buttons
- assets/ — reference images used in the page

## How to run
1. Keep the folder structure unchanged.
2. Open `index.html` in Chrome, Edge, or another browser.
3. No server is required for the demo interactions.

## Main working interactions
- Navigation links scroll to sections.
- Mobile menu opens/closes.
- Blog category filters work.
- Blog search works.
- Read Article buttons open article modals.
- About Me and View Project buttons open modals.
- Newsletter form shows a confirmation.
- Contact form shows a confirmation.
- Back to top works.
- Responsive layout adapts to desktop, tablet, and mobile.

The layout uses a modular/grid approach with repeated columns and consistent spacing, matching the HCI lesson's emphasis on hierarchy, alignment, consistency, and responsive web design.
